# karkichtn Matrix Profile — fixed package

This package fixes the broken images in `karkichtn/karkichtn`.

## What changed

- Replaced the old external GitHub stats image URLs with SVG cards generated by GitHub Actions and committed to this repository.
- Added a `push` trigger to the contribution snake workflow so it creates the `output` branch assets after updates to `main`.
- Kept the Matrix animated banner and terminal-green theme.
- Featured three verified repositories: `portfolio-website`, `Banking-Website`, and `DATA-SCIENCE`. The `cpp` repository was empty when checked, so it is not presented as a featured project.
- Included temporary local SVG placeholders; the profile-card workflow replaces them with live data on its first successful run.

## Upload from macOS Terminal

1. Extract this ZIP inside your Downloads folder. It creates a folder named `karkichtn-profile-fix`.
2. Make sure your existing cloned repository folder is `~/Downloads/karkichtn-upload` (the folder created earlier when you cloned `https://github.com/karkichtn/karkichtn.git`).
3. Run these commands:

```bash
cd ~/Downloads/karkichtn-profile-fix
cp README.md SETUP.md ../karkichtn-upload/
mkdir -p ../karkichtn-upload/.github/workflows ../karkichtn-upload/assets ../karkichtn-upload/profile
cp .github/workflows/*.yml ../karkichtn-upload/.github/workflows/
cp assets/* ../karkichtn-upload/assets/
cp profile/*.svg ../karkichtn-upload/profile/
cd ../karkichtn-upload
git add README.md SETUP.md .github assets profile
git commit -m "Fix Matrix profile cards and contribution snake"
git push
```

If Git says `nothing to commit`, the new files may already be present; check `git status` and continue to the Actions step.

## Run the workflows once

Open https://github.com/karkichtn/karkichtn/actions.

- Run **Generate Matrix Profile Cards** with **Run workflow**.
- Run **Generate Matrix Contribution Snake** with **Run workflow**.

Both workflows are also configured to run after a push to `main` and then refresh daily.

## Required GitHub setting

In the repository, open **Settings → Actions → General → Workflow permissions**, select **Read and write permissions**, and save. Both workflows need permission to commit generated SVG files to the repository or to the `output` branch.

## Expected generated files

The profile-card workflow refreshes these files in the `profile/` folder:

- `stats.svg`
- `top-langs.svg`
- `pin-portfolio.svg`
- `pin-banking.svg`
- `pin-data-science.svg`

The snake workflow publishes these files to the `output` branch:

- `github-contribution-grid-snake.svg`
- `github-contribution-grid-snake-dark.svg`
